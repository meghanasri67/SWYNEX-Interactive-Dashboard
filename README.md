# SWYNEX Internship – Task 3: Interactive Dashboard

## Project Title
E-Commerce Sales & Customer Analytics Dashboard

## Objective
The objective of this task is to create an interactive dashboard using Power BI to analyze e-commerce sales and customer data.

The dashboard helps users understand overall business performance, sales trends, channel performance, regional performance, and customer segment performance.

## Tool Used
- Power BI
- DAX
- Excel

## Dashboard Features

### KPI Cards
The dashboard includes the following key performance indicators:

- Total Orders
- Total Net Sales
- Total Profit
- Total Quantity

### Visualizations
The dashboard contains:

- Sales Trend by Month
- Sales by Channel
- Sales by Region
- Sales by Customer Segment

### Interactive Filters
Users can interact with the dashboard using filters/slicers such as:

- Year
- Sales Channel
- Region
- Customer Segment

## Key DAX Measures

Some of the measures created for the dashboard include:

- Total Orders
- Total Net Sales
- Total Profit
- Total Quantity

These measures help calculate and display important business metrics dynamically.

## Dashboard Insights

The dashboard helps identify:

- Changes in sales performance over time
- Sales contribution by different channels
- Regional sales performance
- Customer segment contribution
- Overall order and sales performance

## Project Files

- `E-Commerce_Sales_Customer_Analytics.pbix` – Power BI dashboard
- `Dashboard_Screenshot.png` – Dashboard preview

## Conclusion

This project demonstrates the use of Power BI to transform e-commerce data into an interactive and easy-to-understand dashboard. The dashboard provides a clear view of important business metrics and helps users explore the data using interactive filters.
